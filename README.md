# Jyotish Complete Full-Stack Astrology Platform (Phase 5)

Production-ready Vedic Astrology platform featuring a high-precision calculation & classical rules microservice, React + TypeScript frontend, **East Indian SVG chart rendering**, and **Docker / Nginx deployment architecture**.

## What's Added in Phase 5
- **East Indian Chart Renderer**: Traditional square grid layout with diagonal house quadrants.
- **Production Dockerization**: Multi-stage Dockerfile and Docker Compose configuration orchestrating FastAPI backend, Vite React frontend, and Nginx reverse proxy.

## Quick Start with Docker
```bash
docker-compose up --build
```
Access the application at `http://localhost`.
